组件不再各自携带一套颜色和阴影，而是共享文章排版层的视觉语义。下面的样例采用与生产组件相同的 MDC class 命名和 token 名称。

01 / tones & notices
i
信息提示边框、底色和正文都跟随文章主题，不再单独维护一套蓝色。
✓
保存成功成功状态只改变 tone，其余结构保持一致。
!
需要留意状态色承担提示职责，不再依赖厚重阴影制造层级。
×
请求失败错误色与焦点轮廓保持同一套语义来源。
02 / progressive disclosure
›Collapse / 点击查看内容

标题使用 surface，内容使用 card；两层之间通过边框和间距建立秩序，而不是额外投影。

平静的表面不意味着信息贫乏。模糊层只负责隐藏内容，交互仍然由清晰的按钮语义承担。
同一外框。 border、radius、margin 和 surface 在所有组件上保持稳定，状态色只作为局部 accent。
同一焦点。 button、tab、summary 都有可见的 focus-visible 轮廓，交互状态不依赖鼠标悬停。
同一收缩。 移动端只覆盖必要的 gap、padding 和 wrap，不复制一套新的组件样式。
