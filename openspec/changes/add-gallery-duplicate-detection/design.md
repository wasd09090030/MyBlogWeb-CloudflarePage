## Context

Admin 是 Nuxt SPA，API 运行在 Cloudflare Worker，数据位于 D1。现有画廊只保存地址与资源引用，管理列表有 2000 条限制，源图片跨域且短链会重定向，不能直接用于可读取像素的 Canvas。

## Goals / Non-Goals

目标：识别换地址、压缩及缩放后的相同图片；为新增、改地址及批量导入提供默认关闭的可选预检；扫描所有已有记录（含隐藏）；明确展示失败并支持重试；由管理员决定保留。

不包含：AI 识别、自动删除文件、强制唯一约束、裁剪或水印保证、实时后台任务及公开站改造。

## Decisions

1. 浏览器解码图片、白底合成透明像素、缩小为 32×32 灰度，使用低频 DCT 生成 63 位 pHash，辅以颜色均值、方差及宽高比过滤低细节误报。算法版本固定，初始距离阈值保守，结果仅称为疑似重复。
2. 新增会话保护的同源图片读取接口，仅访问已配置图床主机；每次重定向重新校验、禁止携带认证信息、限制类型/字节/超时。不使用图像转换服务或新增运行时依赖。
3. D1 新增按规范化图片地址与算法版本缓存的指纹表；缓存有有效期，主动扫描支持强制重算。地址内容改变但缓存未过期可能暂时无法发现，界面和文档说明。
4. 单独按 id 游标分页读取画廊目录与指纹，不复用截断的管理列表。浏览器限制并发，失败不缓存为成功；首次手动扫描或选择预检时可能需要建立全部指纹。
5. 只有管理员选择预检时才检查整个已有目录及批次内部，编辑排除自身。未选择时直接保存，不请求查重接口。疑似重复与读取失败的候选默认跳过，管理员可明确保留；目录读取失败则终止，不得报告检查完成。已有目录中图片读取失败时显示不完整状态及重试。
6. 独立业务组合式函数和复核组件承载逻辑，页面只负责调用及最终写入。扫描提供逐对预览和逐项人工确认删除，避免相似关系传递导致误删。查重是管理端预检，不强制约束其他 API 客户端或并发导入。
7. 画廊列表和查重复核使用相同删除接口。服务端解析真实 storage key，兼容旧地址及素材短链，检查其他画廊（含隐藏项）、文章封面及 Hero 的关联和旧地址引用；共享文件或未知外部源拒绝删除。复用图床模块删除原文件，仅接受明确成功响应，随后用 D1 batch 事务停用素材、删除画廊和相关指纹。图床失败保留记录；数据库失败时通过图床幂等删除重试收尾。浏览器显示具体失败原因及不可撤销的确认提示。

## Risks / Trade-offs

- 感知指纹存在误报/漏报：采用并排复核，禁止自动删除。
- 远端图片可能不可用或格式不受支持：保留失败原因、重试以及显式继续入口。
- 首次大画廊扫描需下载原图：限制并发、复用持久化缓存、显示进度并允许取消。
- 浏览器解码有资源成本：限制输入字节与像素尺寸，动画只取首帧。
- 同时导入存在竞态：本次最小实现为建议性预检，不承诺事务式唯一性。

## Migration / Rollback

先应用新增的 0006 迁移（0005 已用于日记），再发布 API 和 Admin Pages；首次扫描自动补齐指纹。无已有数据回写或清理。回滚前端/API 即可停用，新增缓存表可保留；不自动运行远端迁移或发布。
